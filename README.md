💼 Proyecto: Prácticas Profesionalizantes
Este sitio fue desarrollado con HTML, CSS y JavaScript como parte de la materia Prácticas Profesionalizantes. Su objetivo principal es mostrar el trabajo realizado por los estudiantes, quienes desarrollaron páginas web para clientes reales de nuestra comunidad.

🎯 Objetivo
Brindar a los estudiantes una experiencia real de trabajo, aplicando sus conocimientos técnicos en proyectos concretos y colaborando con personas u organizaciones que necesitaban presencia en la web.

🧑‍💻 Tecnologías utilizadas
HTML5

CSS3

JavaScript Vanilla
